# Smart Billing Lab

A beginner-friendly JavaScript practice project completed as part of the HackGenix training program.

## About the Project

Smart Billing is a simple billing application that calculates the total amount based on the quantity entered by the user. It applies a discount and adds GST to calculate the final amount.

It also includes a grade checker and JavaScript practice exercises.

## Features

- Calculate the bill based on quantity.
- Apply a 5% or 10% discount depending on the amount.
- Calculate 18% GST.
- Display the final bill amount.
- Check student grades based on marks.
- Validate user inputs.
- Interactive buttons using JavaScript event listeners.

## JavaScript Concepts Practised

- Variables (`let` and `const`)
- Data types and type conversion
- Operators and conditional statements
- Ternary operator
- `switch` statement
- `for` and `while` loops
- Nested loops
- FizzBuzz challenge
- Prime number checking
- DOM manipulation
- Event listeners
- Input validation

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `lab/index.html` in your browser.
4. Enter a quantity and click **Calculate Bill**.
5. Enter marks and click **Check Grade**.
